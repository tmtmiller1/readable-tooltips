[h1]Readable Tool Tips[/h1]

The base game places tooltips close to the cursor, so at larger UI scales, or when a tooltip flips near a screen edge, the first line of text ends up hidden under the pointer. [b]Readable Tool Tips[/b] nudges every tooltip that follows the cursor a small, consistent distance further off it so its text is clear and easy to read.

Tooltips look the same: font, size, color, borders and contents stay as they are. Only their position moves, so the cursor stops covering them. It's a UI-only mod, so gameplay, AI and balance play exactly as before.

[b]What it does:[/b]
[list]
[*]Pushes every cursor-following tooltip, including the map-tile tooltip, clear of the cursor so its text is easy to read.
[*]Flips the offset near screen edges (left of or above the cursor) so tooltips always sit away from the pointer and stay on-screen.
[*]Two offset values set how far tooltips sit from the cursor: one for tooltips over the map and in popups, a smaller one for the HUD buttons.
[/list]

[b]Works with other mods:[/b]
[list]
[*]Only where tooltips are placed changes, not their styling, so modded tooltips (city yields, tech/civic, plot overhauls such as QD Improved Plot Tooltip, ...) render as their authors intended, just shifted.
[*]It works by wrapping the game's own tooltip code, and every base-game file stays in place.
[/list]

[b]Installation:[/b]
[list=1]
[*]Download or subscribe to the mod.
[*]Place the [b]readable-tooltips[/b] folder in the Civilization VII Mods directory.
[*]Enable Readable Tool Tips from Additional Content in-game.
[/list]
