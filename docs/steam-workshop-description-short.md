[h1]Readable Tool Tips[/h1]

The base game drops a tooltip's top-left corner right at the cursor, so the first line of text ends up hidden under the pointer. [b]Readable Tool Tips[/b] nudges every tooltip a small, consistent distance off the cursor so its text is always clear and easy to read.

That is the whole mod. It changes nothing about how tooltips look — not the font, size, color, borders, or contents. It only shifts their position so the cursor stops covering them.

[b]What it does:[/b]
[list]
[*]Pushes every active tooltip clear of the cursor so text is no longer hidden behind the pointer.
[*]Flips the offset near screen edges (left/above the cursor) so tooltips always sit away from the pointer and stay on-screen.
[*]Position only — no font, size, color, or content change of any kind.
[*]One simple offset knob controls how far tooltips sit from the cursor.
[/list]

[b]Works with other mods:[/b]
[list]
[*]Offsets the game's shared tooltip slot without reading or overriding any tooltip's own styling, so modded tooltips (city yields, tech/civic, plot overhauls, ...) render exactly as their authors intended — only their position shifts.
[*]No [i]!important[/i] overrides; any mod can still control tooltip positioning.
[/list]

[b]What it does not do:[/b]
[list]
[*]It does not change tooltip appearance — position only.
[*]It does not change gameplay, AI, or balance.
[*]It does not overwrite base-game files.
[/list]

[b]Installation:[/b]
[list=1]
[*]Download or subscribe to the mod.
[*]Place the [b]readable-tooltips[/b] folder in the Civilization VII Mods directory.
[*]Enable Readable Tool Tips from Additional Content in-game.
[/list]
